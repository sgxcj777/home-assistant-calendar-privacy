# Home Assistant Calendar Integration

This project provides Google Calendar integration for a self-hosted Home Assistant environment.

## Purpose

The integration allows authorized users to connect their own Google accounts and access their Google Calendar information through Home Assistant.

## Google Account Access

Each user independently authorizes access to their own Google account through Google's OAuth 2.0 authorization process.

The application does not ask users to share their Google passwords.

## Data Handling

Calendar information is used to provide calendar functionality within the user's Home Assistant environment and associated services.

For details about data collection, processing, storage, and user rights, please see our [Privacy Policy](./privacy.md).
