# Privacy Policy

**Last updated: 12 November 2026**

## 1. Overview

This privacy policy describes how the Home Assistant Calendar Integration accesses and processes Google user data.

The integration is designed for use with a self-hosted Home Assistant environment. Each user independently authorizes their own Google account using Google's OAuth 2.0 authorization process.

## 2. Information Accessed

Depending on the permissions granted by the user, the application may access:

- Google Calendar account and calendar information.
- Calendar lists and calendar metadata.
- Calendar events, including titles, descriptions, locations, start times and end times.
- Calendar event availability and status information.

The application only requests access necessary to provide its calendar functionality.

## 3. How Information Is Used

Google user data is used to:

- Display calendars and events in Home Assistant.
- Synchronize calendar information with the user's configured services.
- Support calendar-related automation and scheduling functionality.

Google user data is not used for advertising, sold to third parties, or used to determine creditworthiness or eligibility for loans.

## 4. Data Storage and Sharing

Calendar information may be processed and stored within the user's self-hosted Home Assistant environment and associated backend services.

Depending on the user's configuration, calendar metadata and event information may also be stored in a database used by the integration.

Access is restricted according to the application's configured user ownership and access controls.

The application does not sell Google user data or share it with third parties for advertising purposes.

## 5. Google OAuth Credentials

The application uses Google's OAuth 2.0 authorization mechanism.

Users authorize their own Google accounts. The application does not collect or store Google account passwords.

OAuth tokens are handled by the Home Assistant integration and used to maintain authorized access to Google Calendar.

Users can revoke access through their Google Account security settings.

## 6. Data Retention and Deletion

Calendar data may remain in the user's Home Assistant environment or associated database until the user removes the connected account or deletes the relevant stored data.

Users may disconnect their Google account to stop further access.

## 7. Data Security

Reasonable technical and organizational measures are used to protect stored information and OAuth credentials.

Users are responsible for securing their own Home Assistant installation, database, network and connected services.

## 8. User Rights and Contact

Users may request information about the handling of their data or raise privacy-related concerns by contacting the application administrator through the support email address listed on the Google OAuth consent screen.

## 9. Changes to This Policy

This policy may be updated when the application's functionality or data-handling practices change.

## 10. Google API Services User Data Policy

The application's use and transfer of information received from Google APIs will comply with the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.
