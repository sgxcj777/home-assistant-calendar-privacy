# Privacy Policy

**Last updated: 12 November 2026**

## 1. Overview

This privacy policy describes how the Home Assistant Calendar Integration accesses and processes Google user data.

The integration is designed for use with a self-hosted Home Assistant environment. Each user independently authorizes their own Google account using Google's OAuth 2.0 authorization process.
